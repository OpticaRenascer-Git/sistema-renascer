# Sistema Renascer

Sistema de gestão da Óptica Renascer (Trindade-GO): login da equipe, Painel do dia, Clientes e área do Administrador.

- Página: `index.html` e `app.js` (sem etapa de build).
- Banco: Supabase. A chave em `app.js` é a chave pública (publishable); os dados são protegidos pelas regras de acesso (RLS) do banco e pelo login.
- Publicação: GitHub Pages a partir da branch `main`.
